# История изменений

## 1.1.3

- Кнопка закрытия и внутренний скролл теперь появляются только для исходного текста длиннее 1200 символов.
- Короткие переводы используют компактное неинтерактивное окно.
- Длинные переводы используют интерактивное прокручиваемое окно.

## 1.1.2

- Окно перевода стало интерактивным и прокручиваемым.
- Окно перевода больше не пропадает, когда курсор перемещается с исходного текста на окно перевода.
- Добавлена кнопка закрытия окна перевода.
- Улучшено ограничение окна границами видимой области экрана.

## 1.1.1

- Увеличен максимальный размер исходного текста для длинных сюжетных/диалоговых блоков.
- Добавлен перевод длинного текста частями по абзацам/предложениям.
- Окно перевода сделано прокручиваемым для длинных переводов.
- Сохранены переносы между абзацами в окне перевода.

## 1.1.0

- Добавлен переключатель ON/OFF в popup-меню расширения на панели браузера.
- Добавлено разрешение `storage` для сохранения состояния включено/выключено.
- Изменена логика наведения: теперь проверяется точный верхний элемент под курсором.
- Родительские контейнеры больше не сканируются для поиска текста.

## 1.0.3

- Добавлена более строгая логика определения текста под курсором.
- Уменьшено количество ложных переводов родительских контейнеров и пустых областей карточек.

## 1.0.2

- Перевод запускается только при наведении курсора на область отрисованного текста.
- Пустые области внутри больших карточек и `div`-блоков не должны запускать перевод.

## 1.0.1

- Добавлена защита от перевода текста, скрытого за верхними окнами или модальными панелями.

## 1.0.0

- Первая публичная версия.
