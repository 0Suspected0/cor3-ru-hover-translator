# COR3 RU Hover Translator

Неофициальное handmade-расширение Chrome для всплывающего перевода английского текста на русский язык на сайте `cor3.gg`.

Расширение показывает окно с русским переводом, когда курсор наведен непосредственно на английский текст на активных страницах `cor3.gg`.

> **Дисклеймер:** это неофициальная ручная поделка, созданная для личного удобства. Проект не связан с `cor3.gg`, не одобрен и не поддерживается разработчиками сайта. Пользователь сам несёт ответственность за установку, использование, изменение и распространение этого кода.

## Возможности

- Всплывающий перевод видимого английского текста на русский язык на `cor3.gg`.
- Работает как расширение Chrome на Manifest V3.
- Перевод появляется только при наведении курсора непосредственно на область отрисованного текста.
- Пустые места внутри карточек, панелей и больших `div`-блоков не должны запускать перевод всего блока.
- Есть защита от перевода текста, который находится за активным верхним окном, модалкой или панелью.
- Переключатель ON/OFF в popup-меню расширения на панели браузера.
- Поддержка длинного текста:
  - исходный текст до 12000 символов;
  - длинный текст переводится частями;
  - если исходный текст длиннее 1200 символов, окно перевода получает скролл и кнопку закрытия.
- Короткие переводы показываются в компактном неинтерактивном окне без крестика и внутреннего скролла.
- Используется публичный endpoint Google Translate без API-ключа.

## Установка

Код расширения находится отдельно в папке `extension/`. Файлы документации и репозитория находятся в корне.


1. Скачай или клонируй репозиторий.
2. Открой Chrome.
3. Перейди по адресу:

```text
chrome://extensions/
```

4. Включи **Developer mode** / **Режим разработчика**.
5. Нажми **Load unpacked** / **Загрузить распакованное расширение**.
6. Выбери папку `extension/`, в которой находится `manifest.json`.
7. Открой или обнови страницу `https://cor3.gg/`.

## Использование

1. Открой активную страницу на `cor3.gg`.
2. Наведи курсор непосредственно на английский текст.
3. Подожди немного — появится окно с русским переводом.
4. Через иконку расширения на панели браузера можно включать или выключать переводчик.
5. Для длинных текстов можно перевести курсор в окно перевода, прокрутить его или закрыть кнопкой `×`.

## Конфиденциальность

Расширение не собирает аккаунты, пароли, cookies, session-токены или личные файлы.

Когда срабатывает перевод, выбранный видимый английский текст отправляется в Google Translate для перевода. Не наводи курсор на приватный или чувствительный текст, если не хочешь отправлять его во внешний сервис перевода.

## Ограничения

- Проект сделан специально под `cor3.gg`.
- Качество перевода зависит от Google Translate.
- Некоторые динамические элементы интерфейса могут вести себя иначе в зависимости от того, как сайт отрисовывает текст.
- Расширение не является официальным продуктом.
- Код предоставляется как есть, без гарантий и обязательств поддержки.
