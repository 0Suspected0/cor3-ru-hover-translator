# Технические заметки

## Версия

Текущая задокументированная версия: `1.1.3`.

## Целевой сайт

Расширение рассчитано на:

```text
https://cor3.gg/*
```

## Manifest

Расширение использует Chrome Manifest V3.

Важные части манифеста:

- `manifest_version: 3`
- `content_scripts` для `https://cor3.gg/*`
- `action.default_popup` для popup-меню ON/OFF
- разрешение `storage` для сохранения состояния включено/выключено

## Основная логика

Основной файл — `content.js`.

Он:

1. слушает движение мыши;
2. проверяет, включено ли расширение;
3. определяет точный верхний элемент под курсором;
4. читает только прямые отрисованные текстовые узлы этого элемента;
5. игнорирует пустые области внутри больших карточек или панелей;
6. игнорирует текст, скрытый за верхними модальными окнами или панелями;
7. отправляет найденный английский текст в Google Translate;
8. показывает русский перевод во всплывающем окне.

## Точное наведение на текст

Расширение намеренно не сканирует родительские контейнеры. Это важно, потому что многие элементы интерфейса `cor3.gg` — это большие карточки или панели с несколькими вложенными текстовыми элементами.

Цель:

- курсор над реальным текстом: переводить;
- курсор над пустым местом карточки: не переводить;
- курсор над модалкой/окном: не переводить текст за ним.

## Поведение для длинного текста

Настройки:

```js
maxTextLength: 12000
translateChunkSize: 1400
longTextThreshold: 1200
```

Поведение:

- можно обработать текст до `12000` символов;
- длинный текст разбивается на части перед переводом;
- если исходный текст длиннее `1200` символов, окно перевода переходит в long mode:
  - появляется кнопка закрытия;
  - включается внутренний скролл;
  - на окно можно навести курсор, и оно не пропадёт.

## Поведение для короткого текста

Для исходного текста до `1200` символов:

- компактное окно;
- без кнопки закрытия;
- без внутреннего скролла;
- неинтерактивный tooltip.

## Сервис перевода

Используется:

```text
https://translate.googleapis.com/translate_a/single?client=gtx
```

API-ключ не используется и не включён в проект.

## Popup ON/OFF

Файлы:

```text
popup.html
popup.js
popup.css
```

Состояние сохраняется в Chrome local storage под ключом:

```text
cor3TranslatorEnabled
```

## Конфиденциальность

Расширение не собирает логины, пароли, cookies или файлы. Однако текст, выбранный для перевода, отправляется в Google Translate.

## Структура репозитория

Рабочие файлы расширения находятся в:

```text
extension/
```

При ручной установке через `chrome://extensions/` нужно выбирать папку `extension/`, а не корень репозитория.
